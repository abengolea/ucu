Cómo leer estos datos

Las publicaciones son denuncias de terceros: describen indicios, no hechos judicialmente comprobados. La clasificación es multietiqueta y sirve para investigar patrones. Las respuestas atribuidas a la empresa se muestran por separado y conservan su enlace de origen.

Trazabilidad

Una base verificable, no una muestra

Se recorrieron todas las páginas disponibles, se abrió cada publicación y se conservaron los campos necesarios para auditar el resultado. Los nombres de consumidores fueron omitidos de la base preparada.

  • Unidad de análisis: publicación individual identificada por URL e ID del portal.
  • Duplicados: solo se eliminaron URLs idénticas.
  • Importes: los valores ocultados por el portal se mantienen como “[números]”.
  • Categorías: clasificación multietiqueta basada en expresiones observables.
  • Control: 759 páginas procesadas, con HTTP y fecha de extracción registrados.
